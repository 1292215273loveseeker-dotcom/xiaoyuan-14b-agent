A 14B agent that shows its gates.

This is a browser-native demonstration of Xiaoyuan 14B: a portable agent network with a deterministic safety gate, a grounded project-facts action, and an optional bring-your-own-key router. It is not a new foundation model, and it does not claim a live hosted endpoint.

The key is kept in browser-local storage and sent only to the router you enter. It is never placed in the manifest, network definition, prompts, or peer requests. Without a key, the deterministic local path runs.

What this demonstratesobservable surface

The network is data-only. The runtime validates it before any call, runs the front agent, invokes the safety gate first, and exposes one read-only site action. The trace below is the audit surface.

  • Portable network: two agents plus a grounded project-facts action.
  • Deterministic gate: crisis and unsafe branches stop before generation.
  • Grounded capability: facts are read from a published record, not invented.
  • Pluggable inference: the default demo works keyless; BYOK is optional.
  • Honest boundary: local self-evaluation is labeled local; no official rank is claimed.
