# NOTICE

## Base model

This project uses **Qwen2.5 14B Instruct** in GGUF Q4_K_M form, served by
Ollama. The model is not redistributed in this repository. Qwen2.5 is
distributed by Alibaba under its own model license; users must review and
comply with that license before downloading or deploying the weights.

- Model family: Qwen2.5
- Parameter size: 14.8B
- Quantization: Q4_K_M (GGUF)
- Runtime: Ollama, local
- Working context in the tested configuration: 4k tokens

## Scope of this repository

This repository contains:

- project documentation;

- a machine-readable agent card;
- a static public project page.

It does **not** contain:

- the private production source tree;
- user data;
- API keys, credentials, or private endpoints.
