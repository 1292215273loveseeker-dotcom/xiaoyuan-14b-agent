Local-first · safety-gated · 14B

A 14B agent that shows its gates.

Xiaoyuan 14B is not a new foundation model. It is an agent architecture around a quantized 14B open-weight model: deterministic scenario routing, safety gates before generation, task constraint blocks, and output repair after it. Built for a 9 GB, 4k-context, local-first world.

The failure path is the product.

Most agent demos optimize for the happy path. This one makes the critical path deterministic: stop unsafe work before generation, put emergency action first, keep structured output structured, and repair missing fields before the user sees them.

Scenario router

Crisis, health, safety, tool, decision, multi-domain, self-review, general. Priority is explicit.

Deterministic gate

High-confidence cases short-circuit with zero model latency; the label is auditable.

Task constraint block

A compact, task-specific rule block instead of a generic constitution on every turn.

Local model call

Qwen2.5 14B Instruct, Q4_K_M, Ollama, 4k working context, no cloud dependency.

Output post-check

Repair missing emergency-first action, unsafe framing, format drift, and prompt echo.

What it refuses to hide

  • It is an architecture around Qwen2.5 14B, not a new model.
  • It has no public always-on inference endpoint.
  • Local evidence is not an official benchmark run.
  • A human click-through of the production UI is still a release gate.
  • It does not replace a clinician, lawyer, emergency responder, or adviser.
